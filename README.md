# Tic-Tac-Toe Game with Scoreboard

## About the Project
A Python-based Tic-Tac-Toe game where two players compete on a 3×3 board. The game detects wins and draws, supports multiple rounds, and maintains a scoreboard to track player wins.

## Features
- Two-player gameplay
- Interactive 3×3 game board
- Win and draw detection
- Player names and multiple rounds
- Scoreboard to track wins
- Save and load scores using a text file
- Input validation and exception handling

## Technologies Used
- Python
- Lists, Tuples, Sets, and Dictionaries
- Loops and Conditional Statements
- Functions and Recursion
- File Handling and Doctests

## How to Run
1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

   `python tic_tac_toe.py`

## Project Files
- `tic_tac_toe.py` — Main game program
- `scoreboard.txt` — Stores player scores

## Objective
To develop a console-based game while applying fundamental Python programming concepts and collaborative software development practices.
